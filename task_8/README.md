# Task 8 — Team productivity

Run: `..\.venv\Scripts\python.exe -m streamlit run .\task_8\app.py`.

The dashboard calculates delivery from the task fact and allows a sprint selector or all-sprint comparison. Cancelled tasks do not enter active completion denominators. Blocked tasks and reopened counts are shown separately. Use team size, sprint days and work type as context; raw velocity alone is not a team health score.

The app highlights the maximum velocity, longest average cycle time and most reopened items for the selected view. Complete the manual calculation template in `evidence/verification.md` for two teams before claiming the task is fully verified.
